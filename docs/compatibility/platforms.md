# Platform compatibility

| Platform | Architecture | Status | Fixture or CI job | Notes |
|---|---|---|---|---|
| Windows | x64 | partial | `windows-latest` CI; path-scoped `SDL validation / Windows native` | Build/tests plus the checksum-pinned SDL 3.4.10 indexed-window loop, revision-driven presentation, resize/letterboxing, event translation, and managed-mixer-to-SDL dummy stream pass in CI. Physical-device smoke and packaging remain. |
| Linux | hosted runner architecture | partial | `ubuntu-latest` CI; path-scoped `SDL validation / Linux X11` | Managed build/tests pass. The native smoke builds checksum-pinned SDL 3.4.10, stages it beside the published app, and requires X11 indexed presentation plus dummy-audio streaming. Physical display/audio and release packaging remain. |
| macOS | hosted runner architecture | partial | `macos-latest` CI; path-scoped `SDL validation / macOS Cocoa` | Managed build/tests pass. The native smoke builds checksum-pinned SDL 3.4.10, stages it beside the published app, and requires Cocoa indexed presentation plus dummy-audio streaming. An offscreen fallback provides diagnostics but intentionally cannot make the job pass. Physical display/audio and release packaging remain. |

## Cross-platform behavior requiring fixtures

| Area | Status | Reference source | Fixture | Notes |
|---|---|---|---|---|
| Path separators and normalization | compatible for portable virtual paths | `src/Engine/FileMap.cpp`, `src/Engine/Unicode.cpp` | `vfs-layered-catalog`; `vfs-unicode-canonicalization`; directory/ZIP unit tests | Separators, unsafe input, Unicode scalar validity, representative case mappings, normalization-form distinction, collisions, and loose/archive precedence are covered. The culture-independent contract matches the pinned Windows fixture and is cache-versioned; locale-dependent differences between C++ hosts are intentionally not reproduced. |
| Case-sensitive resource lookup | compatible | `src/Engine/FileMap.cpp` | `vfs-layered-catalog` | Case-insensitive virtual lookup passes on Windows and case-sensitive CI filesystems. |
| Unicode paths | compatible for portable lookup and supported host filesystems | startup, save adapter, `src/Engine/FileMap.cpp`, `src/Engine/Unicode.cpp` | `vfs-unicode-canonicalization`; mod-directory, ZIP-name, resource, and save-path unit tests | Original virtual spelling and a deterministic canonical key are retained; composed and decomposed names remain distinct. Unicode mod directories, archive names, resource names, save directories, and save filenames round-trip on supported CI filesystems. |
| Endianness assumptions | partial | binary resource loaders | `binary-endian-primitives`; `indexed-screen-codecs` | Explicit primitives and SPK command words are covered; each future codec still requires fixtures. |
| Input coordinates and desktop quit shortcuts | partial | `src/Engine/Action.cpp`, `src/Engine/CrossPlatform.cpp` | `input-audio-semantics`; unit tests | Reference logical/surface pointer transforms match. | Engine loop scheduling | partial | `src/Engine/Game.cpp`, `src/Engine/Timer.cpp`, `src/Engine/Timer.h` | `FixedStepSchedulerTests`; SDL smoke | Simulation uses exact fixed steps from an injected monotonic clock, supports explicit headless advancement, and bounds catch-up to eight steps like the reference timer default. Rendering remains independently paced. Reference state-specific timers and fast-forward behavior remain future gameplay work. |
| SDL3 native loading | compatible | SDL platform spike | path-scoped Windows/Linux/macOS SDL validation | SDL 3.4.10 loads from the published-app directory and runs the indexed-window event loop through Windows, X11, and Cocoa backends. CI asserts the selected backend, linked SDL version, renderer creation, ticks, changed-frame presentation, unchanged-frame suppression, and dummy-audio streaming. Native handles remain inside `Oxce.Platform.Sdl`; release packaging remains separate. |
| Audio device and mixer boundary | partial | `src/Engine/Game.cpp`, `src/Engine/Sound.cpp`, `src/Engine/Music.cpp` | `input-audio-semantics`; `managed-mixer`; unit tests; cross-platform SDL3 dummy-device smoke; ADR 0006 | PCM clips, playback/bus contracts, headless output, nonlinear reference volume, owned stereo mixing, loops, gain/pan, fixed-point rate conversion, pause/resume, reserved-bus voice policy, SDL3 signed-16 stereo stream output, and graceful device-open failure are implemented.
