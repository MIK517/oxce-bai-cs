# Original asset compatibility

| Format or area | Status | Reference source | Fixture | Notes |
|---|---|---|---|---|
| 8-bit indexed surface model | compatible | `src/Engine/Surface.h`, `src/Engine/Surface.cpp`, `src/Engine/ShaderDraw.h` | `indexed-surface-operations`; unit tests | Zero-initialized storage, dimensions, row/pixel addressing, transparent and exact clipped blits, crop, fill, clipped software primitives, palette-index transforms, 16-color-block inversion, standard shade, replacement-color shade, 256-color palettes, and RGBA presentation conversion are implemented. Primitive rasterization need not be pixel-identical under the compatibility contract; externally visible palette-index transforms match captured reference behavior. |
| Palettes and palette blocks | compatible | `src/Engine/Palette.h`, `src/Engine/Palette.cpp`, `src/Engine/State.cpp`, `src/Mod/Mod.cpp` | `xcom-palettes`; private UFO/TFTD corpus | RGB6-to-RGBA scaling, index-zero transparency, 768-byte blocks with six-byte separators, short-file zero initialization, 16-color block offsets, and bounded palette replacement match. The indexed model does not need the reference SDL duplicate-black workaround because palette indices are never remapped by RGB equality. |
| SCR/DAT raw indexed images | compatible | `src/Engine/Surface.cpp` (`rawCopy`, `loadRaw`, `loadScr`) | `indexed-screen-codecs` | Copies visible bytes, leaves short-image tail pixels unchanged, and ignores overscan bytes. Dimensions remain caller-owned as in the reference surface. |
| SPK images | compatible | `src/Engine/Surface.cpp` (`Surface::loadSpk`) | `indexed-screen-codecs` | Transparent/literal word runs and unknown command words match. Truncated commands fail intentionally instead of synthesizing zero bytes. |
| BDY images | compatible | `src/Engine/Surface.cpp` (`Surface::loadBdy`) | `indexed-screen-codecs` | Literal and repeated runs preserve reference row clipping. Truncated runs fail intentionally. |
| PCK/TAB sprite sets | compatible | `src/Engine/SurfaceSet.cpp`, `src/Engine/SurfaceSet.h`, `src/Engine/Surface.cpp` | `pck-tab-sprites`; private UFO/TFTD/40k/Rosigma corpus | Sequential frame decoding, leading transparent rows, transparent runs, overscan clipping, no-TAB single frames, and 16/32-bit TAB frame counts match. Malformed streams fail intentionally; decoded output is bounded. Two-byte one-frame TAB files used by 40k/Rosigma are handled deterministically instead of relying on the reference loader's incomplete four-byte probe. |
| General image formats | compatible | `src/Engine/Surface.cpp` (`loadImage`), `src/lodepng.cpp`, `src/lodepng.h`, SDL_image GIF/BMP/LBM paths | `indexed-png`; `indexed-gif`; `indexed-bmp`; `indexed-lbm`; private UFO/TFTD/40k/Rosigma/mod corpus | Indexed PNG with 1/2/4/8-bit samples, all PNG filters, Adam7 interlace, original RGBA palette, and transparent-index normalization is compatible and bounded; over 14,000 supplied indexed PNGs decode. GIF logical screens, global/local palettes, interlace, LZW, first-frame selection, SDL palette expansion, and transparency normalization match; all 1,659 supplied GIF files decode. Uncompressed 8-bit BMP row order and palette behavior match and the supplied BMP decodes. Chunky PBM and planar ILBM stored widths, palettes, stencil masks, transparent colors, and uncompressed/ByteRun1 rows match; all 61 supplied TFTD LBM files decode. Truecolor and HAM images remain intentionally rejected because the indexed rendering domain requires 8-bit surfaces. |
| CAT containers | compatible | `src/Engine/CatFile.h`, `src/Engine/CatFile.cpp` | `cat-entries`; private UFO/TFTD/mod corpus | Stored sizes are ignored and entry bounds come from adjacent valid offsets; embedded name chunks remain part of entry data. Malformed tables, descending offsets, and out-of-range entries fail intentionally instead of being skipped or producing unsigned sizes. Entry count and total input size are bounded. |
| GM CAT music | not started | `src/Engine/GMCat.h`, `src/Engine/GMCat.cpp` |  | Catalog extraction and playback-visible content. |
| MAP terrain maps | compatible | `src/Battlescape/BattlescapeGenerator.cpp` (`loadMAP`) | `terrain-map-route`; private UFO/TFTD/40k/Rosigma corpus | Y/X/Z dimensions, X-fastest tile records, top-down level order, and incomplete trailing records match. Declared tiles and total input are bounded; zero dimensions, truncation, and complete records beyond declared dimensions fail intentionally. |
| RMP routes/nodes | compatible | `src/Battlescape/BattlescapeGenerator.cpp` (`loadRMP`), `src/Savegame/Node.h`, `src/Savegame/Node.cpp` | `terrain-map-route`; private UFO/TFTD/40k/Rosigma corpus | Swapped X/Y storage, inverted Z, offsets, five links, reserved metadata, negative directional links, dummy retention, and links to culled nodes match. Incomplete trailing records are preserved and ignored as in the reference; node count and total input are bounded. |
| MCD terrain records | compatible | `src/Mod/MapDataSet.cpp`, `src/Mod/MapData.cpp`, `src/Mod/MapData.h` | `terrain-data`; private UFO/TFTD/40k/Rosigma corpus | Packed 62-byte records, little-endian minimap index, signed terrain level, frame/LOFT arrays, terrain flags, costs, damage fields, and raw unknown bytes are preserved. Incomplete trailing records are preserved and ignored as in the reference; record count and total input are bounded. |
| LOFTEMPS voxel data | compatible | `src/Mod/MapDataSet.cpp` (`loadLOFTEMPS`) | `terrain-data`; private UFO/TFTD/40k corpus | Little-endian 16-bit voxel masks and incomplete odd tails match. Value count and total input are bounded; interpretation of MCD LOFT references remains with the future terrain runtime. |
| Fonts | compatible | `src/Engine/Font.cpp`, `src/Engine/Font.h`, `src/Engine/Unicode.cpp`, `src/Engine/Unicode.h` | `sprite-font`; unit tests | Multi-image Unicode sprite maps, fixed cells, variable-width transparent-column bounds, monospace mode, spacing, question-mark fallback, control/space/NBSP/tab metrics, shade-group text drawing, and allocation-free glyph blits match. The embedded diagnostic DOS font is not required for game/mod data compatibility. |
| Sounds and sound sets | partial | `src/Engine/Game.cpp`, `src/Engine/Sound.cpp`, `src/Engine/SoundSet.cpp` | `input-audio-semantics`; `wave-pcm`; `wave-ms-adpcm`; `wave-ima-adpcm`; private 40k/Rosigma/mod corpus | ADR 0006 establishes immutable PCM clips, effects/UI/ambient/unit-response buses, headless output, and the compatible nonlinear volume curve. Bounded RIFF/WAVE parsing and normalization of 8/16-bit integer PCM, Microsoft ADPCM, and IMA ADPCM to interleaved signed 16-bit samples match SDL; all 2,097 supplied PCM, 203 supplied Microsoft ADPCM, and 3 supplied IMA ADPCM WAV files decode. Original CAT sample conversion, SDL3 output, managed mixing, loops, and positional playback remain explicit follow-ups. |
| Music and AdLib/MIDI | partial | `src/Engine/Music.cpp`, `src/Engine/AdlibMusic.cpp` | ADR 0006 | SDL3 core audio plus an owned managed mixer is selected instead of SDL_mixer. Corpus-driven music decoding, AdLib PCM synthesis, MIDI strategy, playback, looping, and pause/resume remain. |
| FLC video | not started | `src/Engine/FlcPlayer.cpp` |  | Frame timing may differ; decoded content must remain equivalent. |
