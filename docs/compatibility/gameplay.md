# Gameplay compatibility

Phase 6 branches 1 through 3 implement bounded strategic logistics, readiness and economy through
headless commands and an indexed keyboard UI. Supported daily readiness advances while
monthly and unsupported live-world transitions remain guarded.
See [branch 1 acceptance and limitations](../strategic-logistics-status.md).
See [branch 3 research and production status](../strategic-research-production-status.md).
See [the ownership ledger](../phase-6-ownership.md) and
[ADR 0025](../decisions/0025-strategic-time-and-mobile-save-ownership.md).

The 2026-09-26 [world scope split](../phase-6-plan.md#branch-4--world-simulation-and-mission-generation)
sets branch 4b closure at the supported ordinary UFO lifecycle and headless craft
operations. That gate is satisfied and merged in `e10d96f`; see the
[closure evidence](../strategic-world-operations-status.md#branch-4b-closure-evidence-2026-09-26). Branch 4c owns mission/arc/event scheduling,
broader world lifecycles, remaining scripts and pursuit. Branch 4d owns globe UI and
combined branch 4 acceptance. Event payload effects remain guarded for branch 6.

reference daily order, with optional pact cancellation and atomic uncertainty/live

retaliation missions clear matching links before half-hour deletion; loaded
rewrites remove cleared fields while conserving unknown base data. Reference
traces and fresh/cache regressions are recorded in [retaliation cleanup status](../strategic-world-retaliation-cleanup-status.md).

return followers and release mission live counts. Pure forecasts preserve landing
and tactical boundaries; fresh/cache, reload, resource and 72-hour scenarios are
recorded in [crashed UFO status](../strategic-world-crashed-ufo-status.md).
